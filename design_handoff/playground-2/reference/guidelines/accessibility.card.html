Rules
• Body text ≥ 4.5:1, display ≥ 3:1: checked in both themes
• Targets ≥ 44px on touch; clickable chips ≥ 28px with 8px spacing
• Clickable Card, Chip, ListRow get role="button" + Enter/Space
• Sheet: dialog role, focus moves in, Esc closes, focus returns
• Reduced motion: durations → 1ms, no bounce, no sheet slide
• Glyph-only controls need aria-label; decorative glyphs aria-hidden
• Never colour alone: pair status colour with a word or icon
• Forced-colors mode keeps control borders visible
