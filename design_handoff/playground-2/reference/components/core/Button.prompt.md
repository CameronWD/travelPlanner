Pill button with a 2px outline and a hard offset shadow that collapses on press.

```jsx
<Button>+ Add a place</Button>
<Button variant="secondary" size="s">Wishlist</Button>
<Button variant="dashed" block>+ Start a new trip</Button>
```

One primary per screen. Labels are sentence case, verb-first, often prefixed with "+". Press state: translate(2px,2px) and the shadow shrinks to 1px — the button physically pushes into the page.
