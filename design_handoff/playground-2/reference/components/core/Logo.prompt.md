Teepee tent-pin mark and lowercase wordmark; use the lockup in headers, the mark alone at ≤24px.

```jsx
<Logo />
<Logo variant="mark" size={40} />
<Logo variant="wordmark" size={20} color="var(--text-inverse)" />
```

The wordmark always ends in a coral full stop — "teepee." is a statement. Never stretch, recolour the tent, or add a tagline inside the lockup.
