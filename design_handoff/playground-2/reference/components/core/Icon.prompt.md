Lucide icon wrapper at stroke 2.5; requires lucide UMD on the page (see readme › Iconography).

```jsx
<Icon name="bed" />
<Icon name="plus" size={22} color="var(--text-inverse)" />
```

Prefer glyph-free UI where a word does the job (Playground uses text labels on tabs). Icons live inside coloured tiles (radius-s, 2px outline) when they lead a row.
