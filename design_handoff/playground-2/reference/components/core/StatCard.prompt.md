Coloured stat block: caps label, big Bricolage number, optional progress bar.

```jsx
<StatCard label="Spent" value="¥184k" progress={59} sub="of ¥312k est" />
<StatCard label="Sleeps to go" value="26" tone="coral" big />
```

Money is always sun. Countdown is always coral. Numbers use tabular-ish display type, never below 24px.
