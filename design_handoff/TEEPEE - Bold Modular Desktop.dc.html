Rebuild notes for Claude Code

This direction is a Tier-2 restructure on top of the existing token layer. The reskin below is mechanical; the layout notes are real rebuilds.

TIER 1 · TOKENS (unchanged from globals.css)

All colours match the repo exactly — --primary 12 84% 60%, --accent 174 60% 38%, category dots sky/amber/emerald/violet/rose/stone, radius 1rem, warm shadows. Light + dark both designed. One change: display font Fraunces → Space Grotesk (set --font-display). Body stays Plus Jakarta Sans.

TIER 2 · STRUCTURE
  • CountdownHero → solid coral block; route promoted above next steps.
  • BudgetGlance shows estimated vs spent-so-far (no invented budget cap).
  • Chunky modular tiles, category-square icon chips, pill quick-actions.
  • Desktop: max-w-5xl, TripNav underline, right rail where phone stacks.
STILL TODO IN REBUILD

Maps are stylized placeholders — wire real Leaflet + add a dark tile style (Carto Dark Matter). Discreet "workspace" reskin must keep working (keep components token-driven). Surfaces not yet mocked: Journal, Files, Checklists, Settings, Travelling/Past home phases.
