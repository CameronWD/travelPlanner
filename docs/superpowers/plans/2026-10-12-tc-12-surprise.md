# TC-12 Surprise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Stop or an Item that one Traveller (the planner) is arranging and that a chosen set of other Travellers (the surprised) can see the outside of but not the inside, everywhere the plan is shown, until it is revealed.

**Architecture:** Three nullable columns on `Stop` and `Item` carry the Surprise (planner, who is surprised as a JSON string array, revealed-at). A pure core (`lib/surprise.ts`) decides a row's state. One server loader (`lib/surprise-visibility.ts`) runs a tiny pre-query per request and hands every reader the hidden id sets, ready-made Prisma `where` fragments (filtering happens in the query, ADR 0051's rule), and masked placeholder Items for surprised Items. One server guard (`lib/surprise-guard.ts`) refuses writes inside a Surprise by a surprised viewer and tells the Activity recorder which Surprise a row is inside, so the feed filters by a stamp instead of resolving entities. A drift guard test lists every reader and fails when one skips the loader.

**Tech Stack:** Next.js (read `node_modules/next/dist/docs/` before touching app code), Prisma 7 (`@prisma/client`, Postgres), Vitest (node project for `*.test.ts`, happy-dom for `*.test.tsx`), zod 4, lucide-react, `@modelcontextprotocol/sdk` for the MCP tools.

**Spec:** `docs/specs/2026-10-12-tc-12-surprise.md`. Domain: CONTEXT.md **Surprise** (the product rules; read it first, it is the authority on what a surprised Traveller may see).

## Global Constraints

- Branch `feat/tc-12-surprise-2026-10-12`. Never commit to `main`. Never push or deploy. Never run `npm run feedback:*`, `db:seed:real`, or anything that reads `.env.production.local`.
- Filtering is **in the Prisma `where`**, never only at render time (ADR 0051). A reader that loads inside-rows and drops them in JS is a defect.
- Every `where` fragment from `lib/surprise-visibility.ts` is spread with its `AND` key, so it never collides with `REAL_PLAN`, `planScope()`, `WISHLIST_IDEA_WHERE` or `THINGS_TO_DO_WHERE`, all of which set `forkId`/`stopId`/`date` keys directly. If a reader already has an `AND`, merge the arrays.
- Nullable columns are filtered as `{ OR: [{ col: null }, { col: { notIn: ids } }] }`, never `NOT: { col: { in } }` (SQL `NOT IN` drops NULL rows).
- No Prisma `enum`, no `Json` column types: JSON goes in a `String` (schema convention, `docs/HANDOFF.md`).
- Copy style: no em dashes, no semicolons in user-facing prose (`test/copy-style.test.ts`). Control names quoted by the help guide must exist verbatim in UI source: "Make it a surprise", "Reveal the surprise", "Surprise for…" (with the single-character ellipsis `…`).
- The wording "Surprise, planned by {first name}" is what a surprised Traveller sees; "Surprise for {names}" is what the planner and helpers see. Names come from `travellerFirstName()` in `lib/traveller.ts`.
- Verification per task: `npx vitest run <the test files worked>` in the loop; when done `npx vitest related --run <changed source files>` + `npx tsc --noEmit` + `npx eslint <changed files>`. Not the full suite, not `next build`, until Task 14.

## Review Focus

1. **An Item with no Stop that is dated inside a Surprise Stop's range** is not inside the Surprise (membership is by `stopId`, ADR 0049 sets it for scheduled Items). Task 2's loader test pins that such an Item stays visible.
2. **A surprised viewer re-dating an earlier Stop** must still ripple the Surprise Stop's dates (dates are not secret) while `updateStop` on the Surprise Stop itself is refused. /**
 * Surprise (CONTEXT.md): the pure rules. A Stop or Item carries three
 * columns (SURPRISE_SELECT); this module decides what state they put it in
 * and who is surprised by it. No database here; lib/surprise-visibility.ts
 * is the server side.
 */
import { addDays } from "@/lib/dates";
import { instantToZonedDateISO } from "@/lib/tz";
import { travellerFirstName, type TravellerLike } from "@/lib/traveller";

export const SURPRISE_SELECT = { surprisePlannerId: true, surpriseForIds: true, surpriseRevealedAt: true } as const;

export interface SurpriseColumns {
  surprisePlannerId: string | null;
  surpriseForIds: string | null;
  surpriseRevealedAt: Date | null;
}

/** What decides the automatic reveal: the Stop's departDate or the Item's date, read in the Stop's zone. */
export interface SurpriseOver {
  endDate: string | null;
  timezone: string | null;
}

export type SurpriseState = "none" | "live" | "revealed";

export function parseSurpriseFor(json: string | null | undefined): string[] {
  if (!json) return [];
  try {
    const parsed: unknown = JSON.parse(json);
    if (!Array.isArray(parsed)) return [];
    return parsed.filter((v): v is string => typeof v === "string");
  } catch {
    return [];
  }
}

export function serializeSurpriseFor(ids: Iterable<string>): string {
  return JSON.stringify(Array.from(new Set(ids)).sort());
}

/** The day the Surprise reveals itself: the day after it is over (never on the day). */
export function autoRevealDate(over: SurpriseOver): string | null {
  return over.endDate ? addDays(over.endDate, 1) : null;
}

export function surpriseState(row: SurpriseColumns, over: SurpriseOver, now: Date): SurpriseState {
  if (!row.surprisePlannerId) return "none";
  if (row.surpriseRevealedAt) return "revealed";
  const reveal = autoRevealDate(over);
  if (!reveal) return "live";
  const today = instantToZonedDateISO(now, over.timezone ?? "UTC");
  return today >= reveal ? "revealed" : "live";
}

/** A null viewer (a Share link, the Calendar feed) is surprised by every live Surprise. */
export function isSurprisedBy(row: SurpriseColumns, over: SurpriseOver, viewerId: string | null, now: Date): boolean {
  if (surpriseState(row, over, now) !== "live") return false;
  if (viewerId === null) return true;
  return parseSurpriseFor(row.surpriseForIds).includes(viewerId);
}

export interface SurpriseView {
  plannerId: string;
  plannerName: string;
  forIds: string[];
  forNames: string[];
  youAreSurprised: boolean;
}

export function surpriseView(
  row: SurpriseColumns, over: SurpriseOver, viewerId: string | null,
  members: readonly TravellerLike[], now: Date,
): SurpriseView | null {
  if (surpriseState(row, over, now) !== "live") return null;
  const byId = new Map(members.map((m) => [m.id, m]));
  const planner = byId.get(row.surprisePlannerId!);
  const forIds = parseSurpriseFor(row.surpriseForIds);
  return {
    plannerId: row.surprisePlannerId!,
    plannerName: planner ? travellerFirstName(planner) : "a Traveller",
    forIds,
    forNames: forIds.map((id) => { const m = byId.get(id); return m ? travellerFirstName(m) : "a Traveller"; }),
    youAreSurprised: viewerId === null || forIds.includes(viewerId),
  };
}

function joinNames(names: string[]): string {
  if (names.length <= 1) return names[0] ?? "no one";
  return `${names.slice(0, -1).join(", ")} and ${names[names.length - 1]}`;
}

export function surpriseLine(view: SurpriseView): string {
  return view.youAreSurprised
    ? `Surprise, planned by ${view.plannerName}`
    : `Surprise for ${joinNames(view.forNames)}`;
}

// ...types from the Interfaces block...

const EMPTY_WHERE = { item: {}, accommodation: {}, reminder: {}, dayTitle: {}, note: {}, attachment: {}, cost: {}, activity: {} };
export const NO_SURPRISES: SurpriseVisibility = {
  viewerId: null, isEmpty: true, hiddenStopIds: [], hiddenRootItemIds: [], hiddenItemIds: [],
  hiddenAccommodationIds: [], hiddenRootIds: [], hiddenTargetIds: [], hiddenOwnerIds: [],
  placeholderItems: [], where: EMPTY_WHERE,

function nullableNotIn(col: string, ids: string[]) {
  return { OR: [{ [col]: null }, { [col]: { notIn: ids } }] };
}

export async function loadSurpriseVisibility(tripId: string, viewerId: string | null, opts: { now?: Date } = {}): Promise<SurpriseVisibility & { views: { stops: Map<string, SurpriseView>; items: Map<string, SurpriseView> } }> {
  const now = opts.now ?? new Date();
  const [stops, items] = await Promise.all([
    db.stop.findMany({
      where: { tripId, surprisePlannerId: { not: null }, surpriseRevealedAt: null },
      select: { id: true, departDate: true, timezone: true, ...SURPRISE_SELECT },
    }),
    db.item.findMany({
      where: { tripId, surprisePlannerId: { not: null }, surpriseRevealedAt: null },
      select: {
        id: true, forkId: true, stopId: true, date: true, startTime: true, endTime: true, sortOrder: true,
        ...SURPRISE_SELECT, stop: { select: { timezone: true } },
      },
    }),
  ]);
  const liveStops = stops.filter((s) => surpriseState(s, { endDate: s.departDate, timezone: s.timezone }, now) === "live");
  const liveItems = items.filter((i) => surpriseState(i, { endDate: i.date, timezone: i.stop?.timezone ?? null }, now) === "live");
  if (liveStops.length === 0 && liveItems.length === 0) return { ...NO_SURPRISES, viewerId, views: { stops: new Map(), items: new Map() } };

  const views = {
    stops: new Map(liveStops.map((s) => [s.id, surpriseView(s, { endDate: s.departDate, timezone: s.timezone }, viewerId, members, now)!])),
    items: new Map(liveItems.map((i) => [i.id, surpriseView(i, { endDate: i.date, timezone: i.stop?.timezone ?? null }, viewerId, members, now)!])),
  };
  const hiddenStops = liveStops.filter((s) => isSurprisedBy(s, { endDate: s.departDate, timezone: s.timezone }, viewerId, now));
  const hiddenRootItems = liveItems.filter((i) => isSurprisedBy(i, { endDate: i.date, timezone: i.stop?.timezone ?? null }, viewerId, now));
  if (hiddenStops.length === 0 && hiddenRootItems.length === 0) return { ...NO_SURPRISES, viewerId, views };

  const hiddenStopIds = hiddenStops.map((s) => s.id);
  const [insideItems, insideAccs] = hiddenStopIds.length
    ? await Promise.all([
        db.item.findMany({ where: { tripId, stopId: { in: hiddenStopIds } }, select: { id: true } }),
        db.accommodation.findMany({ where: { tripId, stopId: { in: hiddenStopIds } }, select: { id: true } }),
      ])
    : [[], []];
  const hiddenRootItemIds = hiddenRootItems.map((i) => i.id);
  const hiddenItemIds = Array.from(new Set([...hiddenRootItemIds, ...insideItems.map((i) => i.id)]));
  const hiddenAccommodationIds = insideAccs.map((a) => a.id);
  const hiddenRootIds = [...hiddenStopIds, ...hiddenRootItemIds];
  const hiddenTargetIds = [...hiddenStopIds, ...hiddenItemIds, ...hiddenAccommodationIds];
  const hiddenOwnerIds = [...hiddenItemIds, ...hiddenAccommodationIds];
  return {
    viewerId, isEmpty: false, hiddenStopIds, hiddenRootItemIds, hiddenItemIds, hiddenAccommodationIds,
    hiddenRootIds, hiddenTargetIds, hiddenOwnerIds,
    placeholderItems: hiddenRootItems
      .filter((i) => !hiddenStopIds.includes(i.stopId ?? ""))
      .map((i) => ({

        hiddenFromShares: false as const, sortOrder: i.sortOrder, photoAttachmentId: null, sourceItemId: null,
        surprise: views.items.get(i.id)!,
      })),
    where: {
      item: { AND: [nullableNotIn("stopId", hiddenStopIds), { id: { notIn: hiddenRootItemIds } }] },
      accommodation: { AND: [nullableNotIn("stopId", hiddenStopIds)] },
      reminder: { AND: [nullableNotIn("stopId", hiddenStopIds)] },
      dayTitle: { AND: [{ stopId: { notIn: hiddenStopIds } }] },
      note: { AND: [nullableNotIn("targetId", hiddenTargetIds)] },
      attachment: { AND: [nullableNotIn("targetId", hiddenTargetIds)] },
      cost: { AND: [nullableNotIn("ownerId", hiddenOwnerIds)] },
      activity: { AND: [nullableNotIn("surpriseOfId", hiddenRootIds)] },
    },
    views,
  };
}

import { notFound } from "next/navigation";
import { db } from "@/lib/db";
import { SURPRISE_SELECT, isSurprisedBy, surpriseState } from "@/lib/surprise";

const STOP_SELECT = { id: true, departDate: true, timezone: true, ...SURPRISE_SELECT } as const;

async function stopRoot(stopId: string, now: Date) {
  const stop = await db.stop.findUnique({ where: { id: stopId }, select: STOP_SELECT });
  if (!stop) return null;
  const over = { endDate: stop.departDate, timezone: stop.timezone };
  return surpriseState(stop, over, now) === "live" ? { root: { type: "STOP" as const, id: stop.id }, row: stop, over } : null;
}
async function itemRoot(itemId: string, now: Date) {
  const item = await db.item.findUnique({
    where: { id: itemId },
    select: { id: true, stopId: true, date: true, ...SURPRISE_SELECT, stop: { select: { timezone: true } } },
  });
  if (!item) return null;
  const over = { endDate: item.date, timezone: item.stop?.timezone ?? null };
  if (surpriseState(item, over, now) === "live") return { root: { type: "ITEM" as const, id: item.id }, row: item, over };
  return item.stopId ? stopRoot(item.stopId, now) : null;
}
async function resolve(ref: SurpriseRef, now: Date) {
  if ("stopId" in ref) return ref.stopId ? stopRoot(ref.stopId, now) : null;
  if ("itemId" in ref) return itemRoot(ref.itemId, now);
  if ("accommodationId" in ref) {
    const acc = await db.accommodation.findUnique({ where: { id: ref.accommodationId }, select: { stopId: true } });
    return acc?.stopId ? stopRoot(acc.stopId, now) : null;
  }
  if ("target" in ref) {
    const { targetType, targetId } = ref.target;
    if (!targetId) return null;
    if (targetType === "STOP") return stopRoot(targetId, now);
    if (targetType === "ITEM") return itemRoot(targetId, now);
    if (targetType === "ACCOMMODATION") return resolve({ accommodationId: targetId }, now);
    return null;
  }
  const { ownerType, ownerId } = ref.costOwner;
  if (!ownerId) return null;
  if (ownerType === "ITEM") return itemRoot(ownerId, now);
  if (ownerType === "ACCOMMODATION") return resolve({ accommodationId: ownerId }, now);
  return null;
}

export async function surpriseRootFor(ref: SurpriseRef, now = new Date()): Promise<SurpriseRoot | null> {
  return (await resolve(ref, now))?.root ?? null;
}

export async function requireOutsideSurprise(viewerId: string, ref: SurpriseRef, now = new Date()): Promise<SurpriseRoot | null> {
  const hit = await resolve(ref, now);
  if (!hit) return null;
  if (isSurprisedBy(hit.row, hit.over, viewerId, now)) notFound();
  return hit.root;
}

"use server";
import { revalidatePath } from "next/cache";
import { db } from "@/lib/db";
import { requireTripAccess } from "@/lib/guards";
import { requireOutsideSurprise } from "@/lib/surprise-guard";
import { SURPRISE_SELECT, parseSurpriseFor, serializeSurpriseFor, surpriseState } from "@/lib/surprise";
import { surpriseSummary } from "@/lib/activity";
import { TRAVELLER_SELECT, travellerFirstName } from "@/lib/traveller";
import { recordPlanActivity } from "@/lib/activity-guard";
import { notFound } from "next/navigation";

export type SurpriseKind = "STOP" | "ITEM";
type Result = { success: true } | { success: false; errors: Record<string, string[]> };

async function loadRow(kind: SurpriseKind, id: string) {
  if (kind === "STOP") {
    const s = await db.stop.findUnique({ where: { id }, select: { id: true, tripId: true, forkId: true, name: true, departDate: true, timezone: true, ...SURPRISE_SELECT } });
    return s && { ...s, label: s.name, over: { endDate: s.departDate, timezone: s.timezone }, enclosingStopId: null as string | null };
  }
  const i = await db.item.findUnique({ where: { id }, select: { id: true, tripId: true, forkId: true, title: true, date: true, stopId: true, ...SURPRISE_SELECT, stop: { select: { timezone: true } } } });
  return i && { ...i, label: i.title, over: { endDate: i.date, timezone: i.stop?.timezone ?? null }, enclosingStopId: i.stopId };
}

export async function setSurprise(input: { kind: SurpriseKind; id: string; forIds?: string[] }): Promise<Result> {
  const row = await loadRow(input.kind, input.id);
  if (!row) notFound();
  const { user } = await requireTripAccess(row.tripId);
  if (row.enclosingStopId) await requireOutsideSurprise(user.id, { stopId: row.enclosingStopId });
  const now = new Date();
  if (surpriseState(row, row.over, now) === "live" && row.surprisePlannerId !== user.id) {
    return { success: false, errors: { _: ["Only the planner can change a surprise."] } };
  }
  const members = (await db.tripMember.findMany({ where: { tripId: row.tripId }, select: { user: { select: TRAVELLER_SELECT } } })).map((m) => m.user);
  const memberIds = new Set(members.map((m) => m.id));
  const forIds = input.forIds ?? members.map((m) => m.id).filter((id) => id !== user.id);
  if (forIds.includes(user.id) || forIds.some((id) => !memberIds.has(id))) {
    return { success: false, errors: { forIds: ["Choose Travellers on this trip, other than yourself."] } };
  }
  if (forIds.length === 0) return { success: false, errors: { forIds: ["Choose at least one Traveller."] } };
  const data = { surprisePlannerId: user.id, surpriseForIds: serializeSurpriseFor(forIds), surpriseRevealedAt: null };
  if (input.kind === "STOP") await db.stop.update({ where: { id: row.id }, data });
  else await db.item.update({ where: { id: row.id }, data });
  const forNames = forIds.map((id) => travellerFirstName(members.find((m) => m.id === id)!));
  await recordPlanActivity(row.forkId, {
    tripId: row.tripId, verb: "UPDATED", entityType: input.kind, entityId: row.id, entityLabel: row.label,
    surpriseOf: { type: input.kind, id: row.id },
    changes: surpriseSummary({ kind: "set", kindOf: input.kind, label: row.label, forNames }),
  });
  revalidatePath(`/trips/${row.tripId}`, "layout");
  return { success: true };
}

export async function revealSurprise(input: { kind: SurpriseKind; id: string }): Promise<Result> {
  const row = await loadRow(input.kind, input.id);
  if (!row) notFound();
  const { user } = await requireTripAccess(row.tripId);
  if (surpriseState(row, row.over, new Date()) !== "live") return { success: false, errors: { _: ["This isn't a surprise."] } };

    await db.stop.update({ where: { id: s.id }, data: { surpriseRevealedAt: now } });
