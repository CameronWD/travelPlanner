# The 19 November notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the eight Feedback notes of 19 Nov 2026: a loaded Day carousel, a Still to book sheet, dismissable Reminders, a Feedback panel that fills the space above the phone keyboard, three small layout fixes, and honest loading states.

**Architecture:** The Day page renders a slot for every day of the Trip; the three near days are awaited as now and the rest stream behind per-slot `<Suspense>` in the same response, so there is no client data fetch. The carousel owns "which day is shown" as client state and writes the URL with `window.history.pushState`. Reminder dismissal is one nullable column reached through the existing `updateReminder` patch. The single `loading.tsx` becomes a client component that picks its shape from the pathname.

**Tech Stack:** Next.js (this repo's version: read `node_modules/next/dist/docs/` before using any Next API), React 19, Prisma + Postgres, Tailwind, Vitest + Testing Library.

**Spec:** `docs/specs/2026-11-19-nov-19-notes.md`
