- **Claude connection · Christmas in Europe 2026 · Cam · 2026-11-17** — `cmwkj1hyc000e08l9ce0fvwql`
  Tight-turnaround warnings give a lot of false alarms for walking routes.
  
  The travel-time check measures from each thing to do's single address to the next one's address. But many things are routes or wanders that end somewhere other than where they're pinned, so the check measures from the wrong place. Examples on Christmas in Europe 2026:
  - "Tower Bridge + South Bank walk" is pinned at Tower Bridge but ends at Westminster Bridge, so it flags 0 min vs ~34 min to "Westminster Bridge & Big Ben".
  - "Oxford Street & Regent Street" is pinned at Hamleys but ends at Marble Arch, so it flags 0 vs ~23 min to Winter Wonderland, which is right there.
  - "Buckingham Palace" → "The Mall to Trafalgar Square": the Mall walk starts at the palace, but it's pinned at Trafalgar Square, so it flags 0 vs ~20 min.
  - "Eiffel Tower" → "Hot chocolate hunt": the walk back is part of the hot chocolate item itself.
  - "Eisbachwelle" → "Englischer Garten": the garden's address is a district centroid, though the wave is at the garden's edge.
  
  Ideas:
  1. Allow an optional start and end point (or "ends at") on a thing to do, and use the end point for the next leg's travel time.
  2. A "walking route / wander" type that suppresses the check, or treats the next item as continuous.
  3. Per-warning "dismiss / this is fine" so a reviewed warning stops showing (and comes back if the times change).
  4. Possibly use walking time, not public transport, when two points are under ~1.5 km apart (several warnings quoted PT times for short walks).
  _/claude_

- **Claude connection · Christmas in Europe 2026 · Cam · 2026-11-17** — `cmwkj3pnm000i08l9taojobzc`
  Wish: a "walking" option for a Stop's local travel mode, and/or per gap.
  
  Right now a Stop's travel mode can only be drive, public transport or automatic. In Paris we walk almost everything, but the tight-turnaround check quotes public transport for hops of ~1.5–2 km. Examples on 17–18 Dec: Rue Cler → Pont de Bir-Hakeim, ~20 min walk, flagged against a ~32 min public transport trip; Café Pli → Place des Vosges, ~20 min walk, flagged against ~22 min public transport.
  
  Ideas:
  1. Add "walking" as a Stop travel mode, perhaps "walk under X km, public transport beyond".
  2. Let us set the mode for a single gap between two things ("we're walking this bit").
  3. When the walk is shorter or about the same as public transport, use the walking time instead.
